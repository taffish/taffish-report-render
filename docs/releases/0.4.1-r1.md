# taffish-report-render 0.4.1-r1

0.4.0-r1 的不可变后继；发布、安装和 cpu5 部署由维护者另行授权。
本次修复通用目录交互，不修改科学数据、原报告或历史 tag/image/Release。

## 修复

- 默认恢复 0.3 的阅读跟随：普通滚动展开当前路径并收起无关分支。
- 多级父子关系、短标题、隐藏组件目录项不再隐式切换为手动模式。
- 默认无独立三角按钮及全部展开/收起工具栏；原无 toc 配置保留旧版两层外观。
- 被目录隐藏的组件仍完整存在于正文，阅读时高亮所属可见章节。
- 根 `[toc] interaction = "manual"` 显式保留 0.4.0 独立开合；默认 `"follow"`。
- 自动跟随优先于节点 `collapsed` 初态；键盘焦点所在分支暂缓自动收起，离开后同步。
- 原生点击/深链/历史/语言切换继续定位；自动跟随不跳转正文、不写 hash、不抢焦点。
- 修复发布前复审发现的窄屏连续滚动错位：缓存正文内相对坐标，并实时读取正文位置；
  原生锚定不足时，在开合及高亮加粗换行结算后即时补偿残余位移，保持可见正文不动。
  新增跨布局断点、含长目录标题的双语连续前进/后退回归。

## 配置与兼容

现有 0.4.0 TOML 原样可解析；默认交互有意改变，需要手动体验时增加根表即可。
schema、normalize、JSON/TOML 迁移往返、validate-spec、strict lint、explain 和 inspect-html
同步支持新字段；未知字段及非法模式拒绝。TOC 诊断索引为 v2，分开记录结构 mode 与
interaction；inspect 继续读取 v1 与更早 HTML。科学正文、资源路径和锚点不重排或改写。

未新增服务、CDN、数据库、模型、自动编号、目录搜索或持久折叠记忆。
TAFFISH 0.11.0 的特殊字符参数需 literal quoting，仍沿用 README/help 中已验证的窄 workaround。
