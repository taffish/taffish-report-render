# taffish-report-render 0.4.0-r1

Immutable feature successor to `0.3.3-r1`. This source candidate is not an
authorization to publish, install, replace a system renderer, or change a
downstream scientific result. Historical tags, images and Hub records remain unchanged.

## Native hierarchical navigation

- Keep the flat section/body order; `sections.toc.parent` defines navigation
  ancestry using stable section IDs, never title-number parsing.
- Sections accept `toc.collapsed` and localized `toc.title`. Every component
  accepts `toc.visible` and localized `toc.title`; collections propagate both
  fields to their expanded components. Hidden navigation entries retain body,
  anchors, source/download controls and asset indexing.
- Separate navigation links from keyboard-accessible collapse buttons; groups
  collapse independently. Include expand-all/collapse-all controls.
- Deep links and history expand ancestors. Reading-position highlighting maps
  a hidden component to its owning visible section. Language/layout changes
  refresh positioning. Navigation collapse never hides or removes print content.
- Write `report_toc.json`, embed the same index in standalone HTML, and expose
  it through `explain --json` and `inspect-html --json`. HTML validation checks
  anchors, ancestry, visibility, active-owner mapping and actual navigation links.

## Strict configuration and compatibility

- No explicit `toc`: preserve the legacy two-level navigation/accordion.
  Any explicit `toc`, including an empty table or empty collection, opts in.
- Schema remains `0.1`; template implementation identity advances to
  `taffish-flow-report-render-0.4`. TOML/JSON normalization and semantic round-trip
  preserve new fields. Existing component types, body titles/numbers, IDs,
  scientific data and resource paths are unchanged.
- Reject unknown TOC fields, wrong types, missing/self/cyclic parents, globally
  colliding/reserved anchors and section depth greater than 64. Short titles
  must cover all declared languages and remain escaped text.
- Section hiding is deliberately unsupported and rejected. This avoids an
  implicit policy for visible descendants of hidden parents.
- Valid old reports remain supported. Previously ambiguous cross-section/component
  ID collisions now fail explicitly. New fields must not be sent to a 0.3 renderer.
- Search, persistent collapse state, type-wide component defaults, initial-depth
  controls and automatic numbering are deferred, not implied capabilities.

## Tests, builds and boundaries

- Pre-publication audit repair: fixed and derived DOM IDs are checked together
  before rendering, including collection expansion; HTML inspection rejects
  duplicate internal IDs too. Existing valid stable anchors are unchanged.
- Offline smoke replays bounded child stdout/stderr with stage and original
  exit status; failure injection prevents diagnostic regressions. A separate
  manifest probe checks main-command and render-subcommand help.
- Document and test the TAFFISH 0.11.0 literal-quoting workaround for wrapper
  paths. `new` prints a correctly double-escaped next command. Plain single-layer
  wrapper quoting remains a core limitation, not a renderer-level argv fix.
- The thin TAF entry now forces a quoted container heredoc to avoid host-side
  expansion of literal shell punctuation. Bundle Bash 5.3.9-r1 (Alpine package)
  for this TAFFISH-native execution path; independent smoke checks its availability.
  No custom entrypoint or host package installation is added. Newline-containing
  wrapper paths remain unsupported; direct container argv is the alternative.
- Real-run media fixture now preserves the structure figure's `.svg` extension
  instead of mislabelling its SVG bytes as PNG. Browser decode/layout assertions
  retain strict checks, include geometry on failure, and close Chromium on errors.

- Synthetic long report: 19 targets, 190 alignment windows, 212 components,
  29 visible and 210 hidden navigation nodes; no customer data.
- Cover DSL/schema/negative inputs, collection expansion, unchanged body/assets,
  TOML/JSON round-trip, tampered HTML/index rejection, and empty sections.
- Keep all prior structured-note, responsive portrait-media, PNG/JPEG/WebP/SVG
  MIME, malicious-text, runtime-pack and real-run regressions.
- The image carries independent stdlib-only TOC and real-image MIME smoke
  fixtures. Tests execute the installed CLI offline in fresh scratch; a
  fungal-equivalent report still requires exactly 8 embedded images.
- Browser checks run outside Dockerfile: Chromium screenshots, deep links,
  history, keyboard, both languages, desktop/narrow reflow and print body retention.
  Full downstream PDF pagination and scientific acceptance remain separate gates.
- Canonical Action is replaced as a whole from fresh `taf 0.11.0 new`; its
  native amd64/arm64 matrix and root build context are unmodified. Build-time
  checks remain lightweight, with no browser, GUI, PDF or screenshot assertions.
- Exact evidence and readiness are in `validation/0.4.0-r1-checklist.md` and
  `validation/0.4.0-r1-validation-receipt.json`; older receipts are historical.

## Runtime and resource contract

Package/runtime identity: `0.4.0-r1`; candidate image:
`ghcr.io/taffish/taffish-report-render:0.4.0-r1`.
Declared native platforms: `linux/amd64`, `linux/arm64`.
Self-developed Apache-2.0 renderer; no separate third-party upstream version.
Bundled JS runtimes retain their pinned versions/checksums and original notices.
Unmodified Alpine Bash 5.3.9-r1 is GPL-3.0-or-later, separate from the renderer's
Apache-2.0 license; README records upstream and Alpine packaging source identity.
No database/model downloader or network service is introduced. User scientific
assets are project-specific inputs, not shared runtime resources.

The final stage omits pip, ensurepip and Python development headers, reducing
both candidate images by about 5 MB without changing the supported renderer CLI.
On Linux Docker, use a host UID/GID runtime policy when ordinary-user ownership
of output directories is required; the README/help include the exact setting.
The renderer does not require root or change input/output ownership itself.

The image installation tree is read-only at runtime. Python bytecode writing is
disabled; temporary test/CLI work goes to fresh `/tmp` scratch, final HTML and
sidecars only to explicit user output paths. Persistent output requires actual
host binds supplied by the TAFFISH wrapper. No runtime chmod, install, download,
CDN, system cache mutation, daemon or listening port is required.
