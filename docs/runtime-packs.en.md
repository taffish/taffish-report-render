# Runtime Packs

`taffish-report-render` can embed optional browser runtimes into the final
standalone HTML report. These runtimes are managed by the tool/package, not by
per-report user code.

Normal users should only configure components in TOML. They should not provide
external JavaScript files, write custom HTML, or patch generated reports.

## Policy

- Runtime packs are bundled with the tool image/source package by maintainers.
- TOML components request runtime use, for example `runtime = "ngl"` or
  `runtime = "igv"`.
- Runtimes are embedded only when needed.
- Real-run tests must use real runtime packs, not test shims.
- Runtime pack updates are maintainer work and should record version, source,
  checksum, and license.

## ECharts

Used by `interactive_plot`.

Supported report uses:

- volcano plot;
- MA plot;
- PCA scatter;
- ORA dotplot.

The component embeds already-computed result rows. Browser controls only adjust
view state, thresholds, colors, filters, and summary counts. They do not
recompute statistics.

## NGL

Used by `structure_viewer` when `runtime = "ngl"`.

Supported report uses:

- PDB structure review;
- target/reference overlays;
- motif or active-site markers;
- model visibility controls;
- style controls such as cartoon, backbone, or trace-style views when supported
  by the runtime.

The component must also embed enough parsed PDB payload to keep a useful
fallback view when WebGL or NGL initialization fails.

## IGV.js

Used by `genome_browser` when `runtime = "igv"`.

Supported report uses:

- compact embedded genome locus review;
- linked review where large tracks remain external;
- FASTA/FAI reference configuration;
- BED, bedGraph, BAM/BAI, VCF/TBI, BigWig, and other IGV-supported tracks.

Small reference and track files can be embedded. Large tracks may remain linked
or user-served, but the report must clearly record that boundary.

## Native HTML/QC Reports

`native_subreport` can package native HTML generated by upstream tools such as:

- MultiQC;
- FastQC;
- fastp;
- Qualimap;
- other static HTML/QC reports when the fixture proves they render correctly.

Heavy native reports should run in their own isolated document context. The
top-level TAFFISH report should not pre-evaluate their JavaScript.

## No Network During Normal Rendering

Normal report generation must not download runtime libraries from a CDN, npm,
or another network source. If a runtime is missing in a development checkout,
maintainer tests should fail with a clear message. Published images should
contain the required runtime packs.

## Test Shim Boundary

Small shims can exist only for smoke/interface tests that check code paths. They
are not publish-ready evidence. `tests/test-real-run.sh` must use real runtime
packs or fail.
